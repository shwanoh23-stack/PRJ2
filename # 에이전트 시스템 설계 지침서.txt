# 에이전트 시스템 설계 지침서
 나는 영업파이프라인 관리 자동화를 수행하는 시스템을 설계하려고 한다.

## 프로젝트 정보
 - 프로젝트명: 영업파이프라인 관리
 - 목표: 영업 파이프라인 관리
 - 입력 데이터: 영업파이프라인에 대한 정보(생성일, 마감일, 취소일, 생성자, 고객사, 금액, 상태),
    액티비티 정보(활동일,활용유형,담당자,내용)
 - 최종결과물: 영업파이프라인 간반보드 관리 웹사이트
 - 필수 조건 및 제한 사항: 생성되서 액티비티가 생성되거나 상태가 변경된 파이프라인은 삭제 불가

## 최종 산출물
하나의 md 설계문서 - antigravity가 실제 구현을 진행할때 참조할 계획서 역할(프로젝트 배경/업무흐름/시스템구조/구현 전략/개발시 고려사항)

## 설계 기준
1. 디렉터리 : 에이전가 추천
2. 품질 검증 : 단계마다 수행 목료 -> 완료 기준 -> 검증 방법 -> 실패시 대응(형식 검사, 필수항목 확인 -> 자동 재시도/관리자 검토 요청)
3. 에이전트 구성: 규모에 따라 단일 또는 기능별 전문 에이전트로 분리
5. 데이터 관리: 중간결과와 산출물은 별도 폴더에 저장해 추적,재실행

## 설계 절차
1단계 요구사항 확인 - 필수정보만 질문(질문은 최소한으로, 없으면 일반적 기본값 적용+근거 기록) -> 2단계 시스템 설계 -> 3단계 검토,보완
